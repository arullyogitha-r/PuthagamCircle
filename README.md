## Technologies Used

### Frontend
- **React.js** – Building the user interface using reusable components.
- **Vite** – Frontend development server and build tool.
- **JavaScript (ES6+)** – Implementing application functionality.
- **CSS3** – Styling and responsive UI design.

### Backend
- **Node.js** – JavaScript runtime for server-side execution.
- **Express.js** – Handling HTTP requests and API endpoints.
- **Better-SQLite3** – Connecting the backend to the SQLite database.

### Database
- **SQLite** – Lightweight relational database for persistent book data.

### Development Tools
- **Git** – Version control.
- **GitHub** – Source code hosting and project management.
